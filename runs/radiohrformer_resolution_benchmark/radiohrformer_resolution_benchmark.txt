Measurement Protocol
--------------------------------------------------------------------------------
- Input tensor shape is [batch, channels, H, W].
- Synthetic input creation and CPU-to-GPU transfer are excluded from latency.
- Warm-up iterations are excluded from latency.
- CUDA latency is measured with CUDA events.
- peak_allocated_mb includes model parameters, the input tensor, output tensor, and temporary forward allocations tracked by PyTorch's CUDA allocator.
- incremental_peak_allocated_mb is peak allocated memory minus allocated memory immediately before timed inference.
- PyTorch allocator memory is not identical to the full process memory reported by nvidia-smi.
